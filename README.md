# Moove List - Intelligent Hiring

Você é um Product Manager Sênior, UX Designer, UI Designer e Software Architect especialista em SaaS B2B.

Sua missão é criar o MVP da plataforma chamada Moove Select.

O objetivo NÃO é criar um ATS.

O objetivo NÃO é criar um CRM.

O objetivo NÃO é criar um sistema de RH.

O objetivo é criar uma plataforma premium para apresentação inteligente de candidatos, ajudando gestores a tomarem decisões de contratação muito mais rápidas.

A filosofia do produto é simples:

Hoje as consultorias entregam currículos.

A Moove Select entrega inteligência.

Toda decisão de UX deve responder apenas uma pergunta:

"Isso ajuda o gestor a decidir mais rápido?"

Caso a resposta seja não, remova.

Prefira simplicidade.

Prefira clareza.

Prefira poucos cliques.

Prefira indicadores visuais ao invés de textos longos.

Todo o sistema deve seguir o conceito de Progressive Disclosure.

Mostrar apenas o essencial.

O restante deve ser expandido somente quando necessário.

A interface deve parecer um software premium inspirado em Apple, Linear, Stripe, Notion e Arc Browser.

Nunca utilizar aparência de ATS tradicionais.

Nunca utilizar tabelas poluídas.

Nunca utilizar excesso de texto.

O sistema deve transmitir organização, elegância e inteligência.

IMPORTANTE

Este MVP não deve tentar resolver todos os problemas do recrutamento.

Ele deve resolver uma única dor de forma excepcional:

Transformar uma shortlist tradicional em uma experiência premium de tomada de decisão.

No futuro o produto será expandido com:

Banco de Talentos

Integração com LinkedIn

Agenda

WhatsApp

CRM

ATS

Pipeline

Marketplace

Videoentrevistas

Análise por IA

Analytics

Por isso, toda a arquitetura deve ser escalável desde o primeiro dia.

Antes de escrever qualquer código:

1. Defina a arquitetura completa.

2. Estruture o banco de dados.

3. Desenhe todas as telas.

4. Crie o Design System.

5. Crie wireframes.

6. Somente depois inicie o desenvolvimento.

O resultado deve parecer um software premium que poderia ser vendido mundialmente para consultorias de recrutamento e departamentos de RH.
